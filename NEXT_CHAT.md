- The 2023 State return reports NIL Special Public Prosecutors and NIL Exclusive Special Public Prosecutors.
- The 2023 State return reports no identified atrocity-prone areas and no Rule 10 Special Officers.
- The 2023 State return reports that the State Level V&MC was not constituted and held no meetings, with NIL Sub-Divisional V&MC reporting. District V&MC constitution/meeting data is not adequately established.
- A 2012 Mizoram Gazette previously constituted a State Level V&MC. This conflicts with the 2023 return and remains an explicit reconciliation issue.
- A 2000 Gazette appointed the Additional Secretary, Home Department as Rule 9 Nodal Officer. The current office-holder was not verified.
- The 2023 State return reports no relief, legal aid, travel/maintenance payments, no Rule 15 implementation plan, and no PoA cases for that reporting year.
