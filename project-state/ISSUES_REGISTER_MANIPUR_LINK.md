# Manipur Issue-Control Link

The authoritative Phase 1 issue register remains `ISSUES_REGISTER.md`. Manipur residuals are recorded in `project-state/MANIPUR_ISSUES_ADDENDUM.md` under PH1-ISSUE-179 through PH1-ISSUE-195.

This linked addendum is part of the issue-control record and must be read with `ISSUES_REGISTER.md` during Manipur continuation.

No existing issue IDs are superseded. Maharashtra PH1-ISSUE-163 through PH1-ISSUE-178 remain separate.
