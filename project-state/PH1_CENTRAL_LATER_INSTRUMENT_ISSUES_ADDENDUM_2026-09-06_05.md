## Classification controls

- Ministry/current-index publication evidence is an endpoint indicator, not a complete Gazette census.
- State rules and State implementation orders are excluded from Central later-instrument sequences unless they amend the Central instrument itself.
- India Code silence is not converted into a negative legal finding where the statute authorises rule-making.
